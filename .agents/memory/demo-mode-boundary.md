---
name: ACCESS-X demo mode boundary
description: Product boundary for AI-dependent accessibility behavior before a live multimodal provider is configured.
---

ACCESS-X should keep Demo Mode visibly labeled until a live multimodal analysis provider is configured. Demo responses may demonstrate the full environment-memory-reasoning loop, but must keep confidence and verification language prominent and must not imply live camera intelligence.

**Why:** Accessibility guidance is safety-sensitive; a polished simulation must not be mistaken for a real-time perception result.

**How to apply:** When adding Gemini or another vision provider, preserve the same structured observation contract and safety copy, then make the mode label reflect the actual provider state.
